# tisan.figma

## 1.0.0
- First version. Reads one Figma page into CSS custom properties, a Tailwind config, and a component manifest.
- Colour, type size, and spacing values that agree are emitted. A name with two values is a conflict and is left out.
- Interactive components list the states they actually have. Hover, active, disabled, and error are missing on Button in the recorded Tervory page, and they are not invented.
- With no `FIGMA_TOKEN`, the only page available is the recorded fixture for file `ksi7ctRwEnN8wbip1yfuhL`.
