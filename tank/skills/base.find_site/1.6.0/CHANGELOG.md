# base.find_site

## 1.6.0
- A distinctive word has to be a whole host label. A longer label that only starts with that word does not count, so one leftover word does not accept another company's site.
- A domain guess stands on the name when the host is exactly that one word and the word is the entire name, even if the record has no phone, ZIP, or street. A one-word name was refused before unless the page showed location proof.
- A name that still has other words, with only one of them distinctive, still comes back empty unless the record's phone, ZIP, or street is on the page.
