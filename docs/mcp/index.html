Tervory for Claude

Connect Claude to the Tervory account you already use. Claude can search your catalogue, look up enriched records, send a short list to be enriched, ask a business-law question, write a sourced market brief, and add a product page to your price watchlist.

Sign-in uses your Tervory account. There is no API key to copy.

Connect

  1. In Claude, add a custom connector.
  2. Use this server address: https://mcp.tervory.com/mcp
  3. Sign in when Claude asks. Pick the organization whose data you want Claude to use.

Claude on the web, the desktop app, the mobile app, and Cowork return to https://claude.ai/api/mcp/auth_callback. Claude Code returns to a page on your own computer. The sign-in screen names that host before you continue.

A person with no organization is asked to use the Tervory app first, so an organization exists to sign in with.

Tools

ToolWhat it does
rig_search Search a catalogue. Read only. Ask for a product name, brand, or sku. Example: “Search my catalogue for a brass widget.”
base_lookup Look up records. Read only. Returns your own enriched business records. You can name words to keep, or a batch id. Example: “Look up records that mention example.com.”
base_enrich Enrich a list. This writes. Send up to 100 rows. You get a batch id back. Example: “Enrich this list of ten companies.”
zenas_research Research a legal question. Read only. United States or South Africa business law. A scope check runs first. Criminal law is refused. Example: “What does the South African Companies Act say a company is?”
market_lab_brief Write a market brief. Read only. One topic, with the source URL and date for each claim that has them. Example: “Write a short brief on brass widget demand.”
tiger_watch Watch a price. This writes. Add one public product page to your price watchlist. Example: “Watch https://example.com/widget and tell me if the price moves by 5%.”

Every answer includes its sources, the model that ran it, and the cost in USD.

Privacy

The full privacy policy is also in privacy.md. The same text is below.

Tervory collects the Clerk user id and the organization id you sign in with, so each call stays inside that organization. Tool arguments you send from Claude, and the results Tank returns, are processed to answer that call. We store short-lived sign-in state (authorization codes for a few minutes, refresh tokens for 30 days) so Claude can stay connected. Enriched rows and price watches are stored as part of that organization’s Tervory account until someone removes them in the app.

We use that data to run the tool you asked for, to show cost, and to keep one organization’s rows away from another. We do not sell it.

Third parties: Clerk checks who you are. Claude, which you chose to connect, sends the tool call and receives the answer. Tank, inside Tervory, runs the work. A market brief or a legal question may cause Tank to read a public page or a configured model in order to answer.

Retention: authorization codes expire in minutes. Refresh tokens expire after 30 days, and reusing an old refresh token signs that connection out. Access tokens expire after one hour. Account records follow the retention of the Tervory app.
