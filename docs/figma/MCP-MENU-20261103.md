# Shared menu product-heading fix

Status: **Approved 3 Nov**. Decision: Claude under the founder’s 3 Nov delegation, recorded in this chat.

Added text property `Product heading#508:0` to shared menu set `180:8549`. Its default is **Trigger**. Both main heading text nodes, desktop `180:8394` and mobile `180:8476`, bind to this property. The desktop/mobile components remain `180:8387` / `180:8467`.

Corrected all 18 visible MCP heading mismatches, including frame `231:11986`, menu `465:46183`, heading `I465:46183;180:8394`. Set product values on 52 existing instances: 36 MCP Rig/Tisan menus (including mobile), 5 Tiger menus, and 11 Rig cart menus. The 95 Trigger menus inherit the unchanged Trigger default. Product names are taken from existing approved frames; no new product wording or menu item was introduced.

The menu items, Close control, styling, positions and frame IDs are unchanged. No nodes were created or deleted. Checks across all 147 instances and both main variants preserve the existing design fingerprints with only the heading characters excluded. Source heading fonts, geometry and layout remain included in those checks.
